# 📚 BookClub - se.yrgo

A simple Spring Boot MVC web application built for the **Controller & View assignment**.  
Developed by **Group: se.yrgo**.

---

## 🎯 Purpose

This project demonstrates the use of:
- **Spring Boot** (Controller + View)
- **Thymeleaf** for server-side rendering
- **Bootstrap 5** for styling
- **Model-View-Controller (MVC)** pattern

The app displays a list of recommended books and lets users explore books by genre.

---

## ⚙️ Requirements

- Java **17 or later**
- Maven **3.8+**
- Browser (Chrome, Edge, Firefox, etc.)

---

## 🚀 How to Run

1. **Clone the repository**

   ```bash
   git clone https://github.com/GurjotKaur1501/bookclub.git
   cd bookclub-se-yrgo

2. **Run the application**

   mvn spring-boot:run

 or if using scripts:
   - run.bat
  3. **Open the application in a browser**
     http://localhost:8080/home
